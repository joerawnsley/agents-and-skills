# Presenter

The table should contain at least the following information

- Event name
- Location
- Event size (number of attendees, or approximate)
- Total number of arrests
- Breakdown of categories of crime along with the number of arrests for the category e.g. 10 arrests for assualt or 5 arrests for robbery
